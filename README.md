# AeroGuard #
* AeroGuard is a military software system for managing a military hangar.

# What is AeroGuard? #
* AeroGuard is a military software that digitalizes the process of monitoring the airplanes, hangars, weapons, fuel and the status of the given hangar.

# Who is it for? #
* AeroGuard is a for engineers, commanders, logistic agents, pilots, weapon loaders.

# Why use AeroGuard? #
* AeroGuard lets you go of the old paper registers and makes it easier for military personal engaged in the hangar to follow what is happening with the machinery on site with little to no errors.
